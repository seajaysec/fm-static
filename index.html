fm-static

Firmware installer for the M-VAVE FM-1

fm-static installs a .fwsc firmware file on an M-VAVE FM-1. Use it when you're finding it hard to get your FM-1 to flash through other means. Bring a .fwsc file and follow the process through to the end.

It is made for the M-VAVE FM-1. The SMK-37 may work; that is completely untested. It checks that the FM-1 comes back running what you installed, not how it sounds.

Do I need official V15 first?

No. Some installers and firmwares caution against installing anything else until you have gone through M-VAVE's official V15. We haven't found a strong reason for that: this page installs any valid package over whatever firmware answers it. The two refusals seen so far (a package bigger than V15's, and a startup-code mismatch) can be got around by installing through a firmware that accepts the package (M-VAVE's V16, or any firmware on a recent fm1-base), or by the restore step, which has not been tried on an FM-1 yet.

If you would like to go through V15 anyway, here it is: the original V15 is inside M-VAVE's Workbench download. Paste https://open.m-vave.com/fm1-workbench in the Firmware file address box, save the file it points to, then choose it in Firmware file: the page finds V15 inside it.

                Wipe application/data area

              2. OPTION
                Also install m-bootloader

                An open bootloader by Julius Vitkauskas (MIT). It replaces M-VAVE's bootloader and stays through firmware updates. Hold PLAY while switching on for a recovery menu, or REC for update mode, even when a firmware won't start. It is written after the firmware, and the FM-1 restarts once more for it. It rewrites the FM-1's startup code (the first 16 KB of flash), the one region a failed write can leave unbootable. A firmware that does not know m-bootloader's installer refuses it and nothing is written. Installing an M-VAVE package afterwards puts M-VAVE's bootloader back.

              3. BEFORE
                Before you install

                Installing can lose what your FM-1 has saved. If the firmware on it has a backup, take one first.

                While it writes, the FM-1's screen shows UPDATING and a bar, or stays dark. Don't unplug the cable or switch the FM-1 off until this page says Done. It can take a few minutes.

                1. RESTORE

                  Restore official startup code

                  The firmware on your FM-1 refused this package at the startup-code check. This mode answers that check with the startup code your FM-1 already has, taken from a Felucca-family file you pick, so the check passes. Then M-VAVE's loader writes the package, its own startup code included.

                  This part carries real risk. Here is what, and why.

                  • It rewrites the one region a failed write can leave unbootable. The first 16 KB of flash holds the code that starts the update loader. Felucca's own loader leaves it alone. If power or USB drops while it is being rewritten, the FM-1 may not start.
                  • This page cannot recover it. If a write is cut off badly, the FM-1 may stop starting and fall back to the chip's ROM boot mode (WL80UBOOT, USB 4C4A:8057), which does not depend on that flash. This page can recognise that state (the "boot mode" button under Your FM-1) and point you to an open tool, but it cannot write from there, and that way back has not been tested. Treat this mode as one with no undo.
                  • Not tested on a device. Felucca's source says M-VAVE's updater rewrites that region as part of every update, with bytes equal to what is already there. Writing different bytes over it is outside that. This page's check bypass passes in a host simulation of Felucca-family step-1 code; the write itself has not been run on an FM-1, and M-VAVE's loader is closed, so a check inside it can't be ruled out.
                  • This package can overwrite saved data. Its flash.bin is larger than V15's, so the loader also overwrites flash above 0x93000, where Felucca-family firmwares keep saved projects. V15 itself stops at 0x93000 and leaves them.
                  • It can also do nothing. If the file you pick does not carry the startup code that is on your FM-1, the firmware refuses again and nothing is written.

                  Lower the odds: USB straight into the computer, laptop on power, this tab in front the whole time. If the write is cut off while the FM-1 is in update mode, replug it and press Finish update.

                  Backup and recovery tools
                  
    
                  Use the tool that matches the state your FM-1 is in. These are separate projects; follow their current instructions.
                  
    
                  
      
                  Normal update
                  M-UPGRADE — M-VAVE's official updater for Windows and macOS. It is documented for firmware updates; raw flash backup support has not been verified.
                  
      
                  Backup or ROM recovery
                  M-Flasher — the recommended desktop route for full-flash backup, backup restore and ROM download-mode recovery on Windows, macOS and Linux. Start with its backup action.
                  
      
                  Command-line recovery
                  MvaveFM1Unbricker — a Windows/Linux alternative for an FM-1 visible as WL82 UBOOT1.00. It makes a double-read backup and verifies application-area writes. Its direct USB recovery backend does not support macOS; check its package restrictions before using it.
                  
      
                  Bricked FM-1
                  FM-1 Transporter — recovery through an extra RP2040/RP2350 board wired to the USB data lines. It has its own Chrome/Edge web app over serial. Hardware and setup are required; this page does not control it.
                  
    
                  
    
                  A firmware's own project export is different from a full-flash backup. Layout Analysis accepts a raw 1 MiB .bin file; it cannot restore it. These external recovery paths have not been tested on a device as part of this page.

                  The manufacturer and current Felucca installer also check the returning firmware identity and offer interrupted-update retries. FM-Static’s Finish update path is implemented but not yet device-tested. Its extra help includes selectable ports, explanations for known refusals, and an opt-in startup-code restore.
                  
      
                  
        
                  About the V15 gate. Choose your next firmware directly. FM-Static checks the connected device and package without imposing a V15-first step. Community installers vary: some enforce that step, others do not. The device can still refuse an incompatible package. Our optional area wipe uses a V15 file as a template, without requiring V15 to be installed first.
                  
        
                  Where the browser stops. This page can inspect a raw backup but cannot read or restore the device’s whole flash. Its MIDI updater cannot replace native access to the chip’s protected USB mass-storage interface. Transporter uses a separate hardware bridge and its own app. Choose a backup or recovery tool.
                  
      
                  
      
                  Comparison sources and limits
        
                  Based on the linked pages and their shipped source, not a fresh hardware test of those tools. Features may change. A checkmark does not promise that every firmware or device state is compatible.
                  
        
                    
          
                  • Manufacturer Flasher: M-VAVE Open Workbench — browser updates, force-mode port search, Open handshake, restart verification, stock return and Open project tools.
                    • 
          
                  • Community reference: Felucca 1.6.1 installer — bundled release, verified stock return, project archives and restart verification. It uses a fixed port-name list, has no Open arming step, and checks the model rather than requiring a V15 starting version.
                    • 
          
                  • M-Flasher, MvaveFM1Unbricker and FM-1 Transporter — separate recovery routes with different platform and hardware requirements.
                    • 
        
                  
        
                  FM-Static’s interrupted-update and startup-code restore paths are implemented but have not been exercised on a device. Dashed branches in the installation workflow identify untested paths. A raw flash image is different from an Open or Felucca project archive.

      any package of the firmware your FM-1 runs now (); the file you installed it from is ideal.
      Only 16 KB of this file is read. Nothing from it is written.
